# Procesamiento de Datos en Batch con Apache Spark (PySpark)

## Descripción de la Solución
Este repositorio contiene la implementación práctica del procesamiento de datos en lote (*Batch*) utilizando **Apache Spark** con **Python (PySpark)**, correspondiente a la Tarea 3 del curso de Big Data de la UNAD. 

El proyecto realiza la carga, limpieza de valores nulos o atípicos, transformaciones y análisis exploratorio de datos (EDA) sobre registros históricos de datos climáticos y ambientales.

## Requisitos del Entorno
* Python 3.8+
* Apache Spark / PySpark (`pip install pyspark`)
* Java Development Kit (JDK 8 o 11)

## Archivos en el Repositorio
* `batch_analysis.py`: Script en Python con el código de PySpark para el procesamiento en lote.
* `README.md`: Descripción e instrucciones del proyecto.

## Instrucciones de Ejecución
1. Clonar o descargar este repositorio.
2. Asegurarse de tener instalado PySpark.
3. Ejecutar el script desde la terminal:
   ```bash
   python batch_analysis.py
